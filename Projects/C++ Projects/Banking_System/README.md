# Banking System

Console banking workflow demonstrating account-oriented operations and file/console interaction.

## Build

From this directory:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o app
```

Run on macOS/Linux:

```bash
./app
```

Run on Windows PowerShell after compiling with a compatible C++ compiler:

```powershell
.\app.exe
```

You can also build every C++ project together from the parent directory with CMake.

## Notes

This project originated as university/learning work and was cleaned for standards compliance, repository hygiene, and easier review. It remains intentionally small and console-focused.
