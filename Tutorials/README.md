# Tutorials Archive

This directory preserves guided exercises and coursework across C++, Python, Django, Flutter/Dart, and algorithms. It is intentionally an **archive of learning history**, not a set of production applications.

Generated IDE indexes, binaries, Python bytecode, notebook checkpoints, and machine-specific metadata were removed during the repository cleanup. Some tutorials target older language/framework versions and may require the historical toolchain used by the course.

For portfolio review, start with the repository's `Projects/` directory instead.
